About this app

Message App is a simple and easy-to-use SMS messaging app designed to help you manage your everyday text conversations.

Send and receive SMS messages, organise conversations and access useful messaging tools from a clean and intuitive interface.

Key Features

  • Send and receive SMS messages
  • View and manage conversations
  • Start new conversations easily
  • Archive conversations
  • Block unwanted numbers
  • Star important messages
  • Schedule SMS messages
  • Recover supported deleted messages from the recycle bin
  • Light and dark theme support
  • Clean and easy-to-use interface

Default SMS App

To provide its core messaging functionality, Message App can be set as your device's default SMS application.

SMS-related permissions are used to send, receive, displays and manage text messages.

Privacy
